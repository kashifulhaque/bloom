How this works

Bloom encrypts a shared report on the sender's device. This page decrypts it here, in your browser, with the key in the link. Bloom's server only holds the encrypted copy and can't read it.

A report uses only what the sender logged. Ovulation days are estimates. It isn't a diagnosis or medical advice.

Bloom is a free, open-source, offline-first cycle tracker.
